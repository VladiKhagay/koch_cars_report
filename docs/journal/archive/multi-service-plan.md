# Plan (from planner, accepted by lead). Brief + ACs: multi-service-jobs.md

## Decisions
- Money: keep `jobs.worker_price` = derived SUM of `job_services.worker_price` (trigger). Generated submitter_share/coworker_share then split the sum unchanged. `job_client_prices` becomes derived per-job sum of new per-row `job_service_client_prices` (NULL if any line lacks a price). jobs_carasso client_* columns keep meaning.
- Atomic create: RPC `create_job(p_site_id, p_worker_id, p_plate, p_vin, p_vin_valid_checksum, p_brand, p_worker_note, p_coworker_ids uuid[], p_service_ids uuid[]) returns uuid`, security invoker, explicit params (no jsonb). Inserts job with service_id = ids[1] (seed trigger adds row 1), then rest `on conflict do nothing`. Empty array raises check_violation.
- `set_job_services(p_job_id, p_service_ids uuid[])` security invoker: dedupe, raise if empty; `update jobs set updated_at=now() where id=p_job_id returning id` (no row => raise 42501, catches expired window); insert missing; delete rows not in list.
- Legacy `jobs.service_id` kept deprecated (first service at creation). Triggers: after insert seeds job_services row (raise check_violation if service_id null and caller non-null); after update of service_id (when changed & not null) replaces set with that one service (old cached builds). Drop in later 0034.
- Stats: view `job_service_lines` (security_invoker): job_id, service_id, worker_price, sort_order, submitter_share, coworker_share, is_first. Allocation ordered by services.sort_order, service_id; each non-last line floor(job_share*line_price/nullif(job_sum,0)*100)/100 (0 when sum 0), last gets remainder; separately for submitter/coworker shares. `job_daily_stats` recreated same columns at service grain from lines; new `job_daily_totals(site_id, worker_id, day, job_count, car_count, worker_cost)` at job grain. Drop unused `job_service_stats`.
- Service filter: `service_ids uuid[]` appended to jobs_worker_view/jobs_manager/jobs_carasso; web uses PostgREST `.overlaps('service_ids', ids)`.
- Views jobs_worker_view / jobs_manager: append `service_ids` and `services jsonb` [{service_id,name_en,name_ru,name_he,catalog_number,worker_price,submitter_share,coworker_share}] ordered by sort_order; keep security_invoker. jobs_carasso: same column list, service_name_*/catalog_number become string_agg (per-item fallback coalesce(name_ru,name_en)), append service_ids + services jsonb [{service_id,name_*,catalog_number,client_unit_price,client_total_price}] — NO worker_price; re-apply revoke/grant. lookup_vehicle / find_previous_job / duplicate_job_summary: create or replace, same signatures, joined names "A, B".
- jobs_apply_worker_price body: new.worker_price := coalesce((select sum(worker_price) from job_services where job_id=new.id), case when tg_op='UPDATE' then old.worker_price else 0 end). Drop jobs_snapshot_client_prices(_ins/_upd)+function.
- Tables: job_services(job_id fk cascade, service_id fk, worker_price numeric not null >=0, created_at, PK(job_id,service_id)); job_service_client_prices(job_id, service_id, unit_price, total_price, updated_at; PK; FK to job_services cascade; set_updated_at trigger). RLS on, revoke from anon.
- Backfill BEFORE new triggers, from jobs where service_id not null (keep worker_price; client prices from job_client_prices); DO-block assertions (row count, sum parity, client price parity, is not distinct from) abort on mismatch. All in one begin/commit.
- RLS job_services: select via `exists (select 1 from jobs j where j.id=job_id)`; insert/delete = jobs_update USING predicate (admin; manager same site; worker submitter within unlocked window, not deleted; never co-workers); update admin only. Do NOT use can_write_job. job_service_client_prices: admin all + carasso select `can_view_job(job_id)`.
- Triggers on job_services: guard (insert: non-null caller => stamp services.worker_price coalesce 0, trusted null caller keeps given price; update: job_id/service_id immutable, non-admin non-null caller price reverted), after insert snapshot client prices (security definer, from service_client_prices, on conflict do nothing), after ins/del/upd-price touch jobs to recompute sum, after delete keep-one (raise if job still exists with zero rows). jobs_client sum trigger on job_service_client_prices upserts job_client_prices.
- Revoke from public/anon + grant authenticated on every function. 0021 guard unchanged.
- Files: supabase/migrations/0033_multi_service_jobs.sql, supabase/verify_0033.sql (read-only checks: parity, pg_policies, anon cannot execute create_job, views security_invoker, jobs_carasso services JSON has no worker_price). Header: deploy order 0033 -> web; rollback web only; 0033 roll-forward only. Do NOT apply anything to any DB.
